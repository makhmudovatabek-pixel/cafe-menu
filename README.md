# АБДУЛЛА АТА кафесі

Телефонға ыңғайланған қазақша және орысша кафе мәзірі. Сайт алғаш ашылғанда қазақ тілі көрсетіледі; бағалар теңгемен беріледі. Әкімші панелі мәзірді, тағамдардың уақытша қолжетімділігін, санаттарды және слайдшоу фотоларын басқарады.

## Жергілікті іске қосу

Node.js 22 LTS немесе жаңарақ нұсқасын орнатыңыз. Бірінші рет `.env.example` файлын `.env` деп көшіріп, `ADMIN_PASSWORD` мәнін өзіңіздің құпиясөзіңізге ауыстырыңыз:

```powershell
Copy-Item .env.example .env
notepad .env
npm start
```

Сайт: `http://localhost:4173`  
Әкімші панелі: `http://localhost:4173/admin`

## Хостингке орналастыру

Бұл жоба Node.js сервері ретінде жұмыс істейді; статикалық файлдарды ғана жүктейтін хостинг жарамайды.

1. Жоба файлдарын Node.js қосымшаларын іске қоса алатын хостингке жүктеңіз.
2. Node.js 22 LTS немесе жаңарақ LTS нұсқасын таңдаңыз. Build командасы қажет емес; іске қосу командасы — `npm start`.
3. Хостингте мына орта айнымалыларын орнатыңыз:
   - `ADMIN_PASSWORD` — ұзын, басқа жерде қолданылмайтын күрделі құпиясөз. `5555` мәнін қолданбаңыз.
   - `NODE_ENV=production` — HTTPS үшін қауіпсіз әкімші cookie файлын қосады.
   - `DATA_DIR` — тұрақты дискідегі қалта, мысалы `/var/data/abdulla-ata/menu`.
   - `UPLOAD_DIR` — тұрақты дискідегі қалта, мысалы `/var/data/abdulla-ata/uploads`.
4. Хостинг доменінде HTTPS қосыңыз. Хостинг `PORT` мәнін өзі берсе, оны қолмен бекітпеңіз — сервер автоматты түрде қолданады.
5. Алғаш іске қосылғанда `DATA_DIR` ішінде мәзір файлы болмаса, ол жобадағы `data/menu.json` үлгісінен көшіріледі. Әкімші панелінен кейінгі өзгерістер осы тұрақты қалтада сақталады.

### Муҳим: сақлаш ва резерв нусха

Мәзір `DATA_DIR/menu.json` файлына, әкімші жүктеген суреттер `UPLOAD_DIR` қалтасына жазылады. Бұл қалталар хостинг қайта іске қосылғанда және жаңа нұсқа орналастырылғанда сақталатын дискіде болуы керек. Уақытша файл жүйесіндегі деректер жоғалуы мүмкін. Сақтық көшірмеге `menu.json` мен жүктелген суреттерді бірге қосыңыз.

Сервер мәзірді JSON файлына, әкімші сеанстарын жадта сақтайды. Сондықтан әзірге сервердің бір данасымен (single instance) іске қосыңыз. Бірнеше данамен жұмыс істеу үшін ортақ дерекқор мен сеанстарды сақтайтын қызмет қажет.

## Әкімші панелі

Пайдаланушы аты — `admin`; құпиясөз жергілікті ортада `.env` файлына, ал хостингте құпия орта айнымалысына жазылады. Әкімші сеансы 30 минуттан кейін аяқталады. Негізгі беттегі `АА` белгісін 2,5 секунд ішінде бес рет басып та кіруге болады. Тағамды «Временно нет в наличии» деп белгілегенде ол клиенттер мәзірінен уақытша жасырылады; белгіні алып тастасаңыз, қайта көрсетіледі.

## Хостингке жүктеу қауіпсіздігі

- `.env` файлын архивке, Git репозиторийге немесе хостингтің жария файлдарына қоспаңыз. Құпиясөзді хостингтің құпия орта айнымалысында орнатыңыз.
- Жоба ішіндегі `.gitignore` жергілікті `.env`, `node_modules` және `public/uploads` мазмұнын Git-ке қоспайды.
- Жүктеу мұрағатында `.env` болмайды. Жүктелген фотоларды жоғалтпау үшін оларды тұрақты `UPLOAD_DIR` дискісінде сақтаңыз.
